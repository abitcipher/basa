# API keys

For shops and partners who keep their listings in another system.

1. Open your **Profile** → **API keys**.
2. Give the key a name and a lifetime (at most a year), and make it.
3. Copy the key right away: it is shown only once.
4. Send it with every request as `Authorization: Bearer basa_…`.

A key can do exactly what you can do on the site: your items and offers, and import if you have access. The full list of requests is at **/api/json/swaggerui**. Revoke a key on the same page when you no longer need it.
