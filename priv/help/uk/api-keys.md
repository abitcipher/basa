# Ключі API

Для магазинів і партнерів, які ведуть свої оголошення в іншій системі.

1. Відкрийте **Профіль** → **Ключі API**.
2. Дайте ключу назву й строк дії (не більше року) і створіть його.
3. Одразу скопіюйте ключ: його показують лише один раз.
4. Надсилайте його з кожним запитом як `Authorization: Bearer basa_…`.

Ключ може робити те саме, що ви на сайті: ваші речі й пропозиції, а також імпорт, якщо у вас є доступ. Повний перелік запитів — на **/api/json/swaggerui**. Відкличте ключ на тій самій сторінці, коли він більше не потрібен.
