# Claves de API

Para tiendas y socios que gestionan sus anuncios en otro sistema.

1. Abre tu **Perfil** → **Claves de API**.
2. Da a la clave un nombre y una duración (como máximo un año) y créala.
3. Copia la clave enseguida: solo se muestra una vez.
4. Envíala en cada petición como `Authorization: Bearer basa_…`.

Una clave puede hacer exactamente lo que tú puedes hacer en el sitio: tus objetos y ofertas, e importar si tienes acceso. La lista completa de peticiones está en **/api/json/swaggerui**. Revoca una clave en la misma página cuando ya no la necesites.
